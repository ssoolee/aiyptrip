# 캐릭터 그림 원본

화면에 올라가는 평안이 그림(`public/character/`)을 만들 때 쓴 원본과 도구를 둔다.
완성본만 커밋하면 "이 그림을 어디서 어떻게 잘랐는지"가 사라져, 도감을 고쳐 그렸을 때
같은 작업을 처음부터 다시 더듬어야 한다.

## MBTI 직업 평안이 16종

| | |
|---|---|
| 원본 | `mbti-job-sheet.png` — 4×4 도감 한 장 (1254×1254) |
| 도구 | `cut-mbti-art.py` — 유형별로 잘라 투명 PNG로 만든다 |
| 결과 | `public/character/mbti/{유형}.png` 16장, 각 280×210, 합쳐 240KB |
| 쓰는 곳 | `src/app/course/mbti/page.tsx` (유형 선택 화면), 직업 이름은 `src/lib/mbti.ts`의 `MBTI_JOBS` |

다시 만들려면 (Pillow 필요):

```
cd docs/character
python cut-mbti-art.py mbti-job-sheet.png ../../public/character/mbti
```

지금 커밋된 16장과 바이트까지 같은 결과가 나온다.

### 잘라낼 때 걸렸던 것

도감을 다시 그려 좌표나 색이 바뀌면 아래 두 가지를 먼저 의심하면 된다. 둘 다
어두운 배경에서는 멀쩡해 보이고 **밝은 배경에 올려야 드러난다** — 양쪽에서 확인할 것.

- **배경은 밝기 문턱으로만 지운다** (`GATE = 160`). 이웃 픽셀과의 차이로 번지게 하면
  안티에일리어싱 경사를 타고 외곽선 안으로 걸어 들어가, 외곽선과 색이 비슷한 남색
  정장(ENTJ 기업가)과 발이 통째로 지워졌다. 몸통 하늘색은 최소채널이 145라 이
  문턱에서 막힌다.
- **라벨 글자는 '비슷한 높이로 두 개 이상 늘어선 줄'을 찾아 지우고, 위쪽에만 쓴다.**
  글자 하나가 캐릭터 외곽선에 1픽셀 닿아 한 덩어리로 잡히는 경우가 있다(ESFP의 `S`).
  아래쪽에 같은 규칙을 쓰면 캐릭터의 두 발이 "같은 높이 두 개"라 글자로 오인돼 발이 잘린다.

행마다 타일 높이가 302/296/277/243으로 달라 균등 분할이 되지 않는다. 좌표는
스크립트 위쪽 `COLS`/`ROWS`에 적어 두었다.
