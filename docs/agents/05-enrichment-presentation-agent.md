# 5. 콘텐츠 보강·프레젠테이션 에이전트 (Enrichment & Presentation Agent)

## 역할/책임

검증 완료된 최종 코스를 받아, 각 장소의 사진, 리뷰 요약, 연락처, 지도
링크/좌표 등 부가 정보를 붙이고, 프론트엔드가 바로 렌더링할 수 있는
응답 스키마로 정리한다. 코스 전체에 대한 한 줄 추천 카피(예: "감성
카페와 물멍 스팟으로 채운 두물머리 힐링 코스")도 생성한다. LLM 없이
일반 백엔드 로직으로도 대체 가능한 단계이지만(순수 데이터 조합), 자연스러운
추천 카피/리뷰 요약 생성 부분만 LLM을 사용한다.

## 입력 스키마

```json
{
  "approved_itinerary": [ "...04번 에이전트 출력..." ],
  "places_detail": {
    "nvr_789012": {
      "name": "두물머리 뷰 카페",
      "photos": ["https://.../1.jpg"],
      "phone": "031-000-0000",
      "naver_map_url": "https://map.naver.com/p/entry/place/...",
      "reviews_raw": ["뷰가 예뻐요", "커피가 평범해요"]
    }
  }
}
```

## 출력 스키마

```json
{
  "trip_title": "감성 카페와 물멍 스팟으로 채운 두물머리 힐링 코스",
  "days": [
    {
      "day": 1,
      "stops": [
        {
          "time_slot": "14:00-15:00",
          "name": "두물머리 뷰 카페",
          "category": "cafe",
          "lat": 37.5341,
          "lng": 127.3198,
          "photos": ["https://.../1.jpg"],
          "phone": "031-000-0000",
          "map_url": "https://map.naver.com/p/entry/place/...",
          "review_summary": "한강 뷰가 아름답다는 평이 많으며, 커피 맛은 무난한 편입니다."
        }
      ]
    }
  ]
}
```

## 사용 가능한 Tool/외부 API

- 없음 (외부 API 신규 호출 없이, 앞 단계에서 이미 수집된 `places_detail`을
  가공/요약)
- 필요시 네이버 검색 API의 place detail 재조회(사진 누락 보완용)

## System Prompt 초안

```
당신은 여행 코스 결과를 사용자에게 보여줄 형태로 다듬는 에이전트입니다.
입력된 코스와 장소 상세정보를 바탕으로:
1. 전체 코스를 한 문장으로 요약하는 매력적인 제목(trip_title)을 만드세요.
2. 각 장소의 reviews_raw를 2문장 이내로 요약(review_summary)하세요.
과장하지 말고 실제 리뷰 내용에 근거해 요약하세요. 출력은 JSON만
반환하세요.
```

## 다른 에이전트와의 관계

- 4번(검증)의 승인된 코스를 입력받는 마지막 단계.
- 결과를 1번(오케스트레이터)에게 반환하면 오케스트레이터가 그대로
  프론트엔드 응답으로 전달.

## 실패/재시도 처리

- 리뷰 데이터가 없는 장소는 review_summary를 생략(빈 문자열)하고 별도
  재시도하지 않음.
- 사진이 없는 장소는 기본 카테고리 아이콘/플레이스홀더 이미지로 대체
  (프론트엔드 처리).
