# PRD-01. AI 코스 추천 기능

## 1. 배경/목표

양평 여행 계획에 필요한 모든 조건(일정, 인원, 이동수단, 예산, 취향,
계절/날씨, 접근성)을 반영해 AI가 실행 가능한 코스를 추천한다. 사용자가
매번 조건을 처음부터 입력하는 부담을 줄이기 위해, 대표 여행 상황을
**원클릭 프리셋**으로 제공하고, 프리셋 선택 시 **사전 생성된 코스를
즉시 보여준 뒤 실시간으로 코스를 추가 생성**하는 하이브리드 방식을
사용한다. 상세 조건 직접 입력(커스텀 추천)도 함께 지원한다.

## 2. 사용자 스토리

- 사용자로서, 별도 입력 없이 "혼자 여행" 버튼만 눌러도 바로 코스
  3개를 볼 수 있으면 좋겠다.
- 사용자로서, 반려동물과 함께라면 반려동물 동반 불가 업체는 아예
  보이지 않으면 좋겠다.
- 사용자로서, MBTI를 입력하면 내 성향에 맞는 코스를 추천받고 싶다.
- 사용자로서, 여행 날짜가 양평 축제 기간과 겹치면 축제 정보를 코스에
  포함해 알려주면 좋겠다.
- 사용자로서, 마음에 드는 프리셋 코스 3개를 다 보고 나면 "더 보기"로
  새로운 코스를 계속 받아보고 싶다.
- 사용자로서, 프리셋이 아니라 직접 기간/인원/예산을 입력해 맞춤 코스를
  받고 싶다.

## 3. 추천 시나리오(테마) 프리셋

| 프리셋 | 자동 매핑 조건(preferences/party 등) | 우선 필터 |
|---|---|---|
| 혼자 여행 | party=solo, preferences=[healing, quiet_cafe, nature] | 조용한 장소 우선 |
| 연인과 함께 | party=couple, preferences=[view_cafe, romantic, photo_spot] | 뷰/감성 스팟 우선 |
| 가족과 함께 | party=family_with_kids, preferences=[experience, kid_friendly] | 주차·아동 편의시설 필수 |
| 친구와 함께 | party=friends, preferences=[activity, lively_food] | 가성비/그룹석 우선 |
| 반려동물과 함께 | pet_friendly=true | `pet_allowed=true` 업체만 노출(하드 필터) |
| MBTI 성향별 | mbti 입력값 → 태그 매핑표(§3.1) 적용 | 매핑된 preferences 가중치 부여 |
| 축제/시즌 연계 | 여행 날짜와 축제 캘린더 매칭 시 festival_tag 부여 | 축제 관련 스팟 1곳 이상 코스 포함 |

> **현재 화면에 있는 것은 혼자 여행·반려동물과 함께·MBTI 성향별 셋뿐이다.**
> 연인·가족·친구·축제는 서비스 결정으로 내렸다(2026-10-26). 표는 설계 근거로
> 남겨 둔다 — 되살리는 방법과 그때 함께 돌아오는 것은 README "코스 유형 3종" 참조.
> 아래 §4~§8의 "프리셋 7종"도 이 결정 이전 기준이다.

### 3.1 MBTI-취향 매핑표 (초안, 운영 중 튜닝 가능)

| MBTI 축 | 매핑 취향 태그 |
|---|---|
| E (외향) | activity, lively_food, popular_spot |
| I (내향) | quiet_cafe, nature, bookstore_cafe |
| S (감각) | local_food, hands_on_experience |
| N (직관) | unique_concept, art_gallery, view_spot |
| T (사고) | efficient_schedule, budget_conscious |
| F (감정) | aesthetic, storytelling_spot |
| J (판단) | tight_schedule, reservation_based |
| P (인식) | flexible_schedule, spontaneous_stop |

- 4글자 MBTI 전체 입력 시 4개 축 태그를 합산 가중치로 반영한다.

### 3.2 MBTI 16유형 큐레이션 코스 (결정)

- "MBTI 성향별" 프리셋은 텍스트 입력 대신 **16유형 버튼 화면**(`/course/mbti`)을 연다.
- 유형 버튼(`/course/mbti/{TYPE}`)을 누르면 근거 자료를 바탕으로 **미리 만들어 둔
  큐레이션 코스**(식당·카페·여행지)를 먼저 보여주고, 그 아래에 **숙소·펜션 추천**을
  별도 섹션으로 보여준다.
- "다른 코스 더 보기"는 §4.2와 같이 에이전트 파이프라인으로 해당 유형의 코스를 추가
  생성한다(§3.1 매핑표의 태그 사용).
- 데이터: 원천 자료 `data/mbti-courses.source.json` → `npm run build:mbti` →
  `src/lib/data/mbtiCourses.json`(장소 좌표·사진 확정). 큐레이션 자료가 없는 유형은
  파이프라인 코스로 대체한다.

### 3.3 축제/시즌 연계

- 양평군 축제 캘린더(예: 세미원 연꽃축제, 물맑은시장 축제 등)를 별도
  데이터 테이블로 관리(`festival_calendar`: 명칭, 기간, 위치, 관련 장소).
- 사용자가 선택한 여행 날짜가 캘린더 기간과 겹치면 해당 축제를
  코스 후보에 우선 포함하고, 코스 카드에 "🎉 세미원 연꽃축제 기간과
  겹쳐요" 배지를 표시한다.

## 4. 하이브리드 제공 방식 — 사전 생성 + 실시간 추가 생성

### 4.1 사전 생성 (배치)

- 프리셋 7종(혼자/연인/가족/친구/반려동물/MBTI 16유형/축제) × 각
  **최소 3개**의 코스를 배치 작업으로 미리 생성해 캐시 DB에 저장한다.
  - MBTI는 16유형 전체를 상시 유지하기보다, 사용량 데이터가 쌓이기
    전까지는 4개 대표 축(EI/SN 조합 등) 우선 생성 후 확장 가능.
- 배치는 `docs/agents/`의 에이전트 파이프라인(오케스트레이터 → 장소검색
  → 코스플래닝 → 검증 → 콘텐츠보강)을 그대로 재사용하되, 트리거만
  "사용자 요청"이 아닌 "스케줄러"로 바뀐다.
- 갱신 주기: 1일 1회 기본. 단, 축제 연계 코스는 축제 시작 임박 시(예:
  D-7) 별도 갱신, 영업시간/휴무 정보 변경 감지 시 즉시 재생성.

### 4.2 실시간 추가 생성

- 사용자가 프리셋 결과 화면에서 "다른 코스 더 보기"를 클릭하면,
  그 시점에 에이전트 파이프라인을 실시간 호출해 새 코스를 생성하고
  기존 목록 뒤에 이어 붙인다(추가 로드 방식, 무한 스크롤 아님 — 버튼
  클릭 기반으로 API 비용 통제).
- 실시간 생성 코스도 검증 에이전트(`04-validation-agent.md`)를 반드시
  거쳐야 하며, 커스텀 입력(직접 조건 입력) 추천도 동일 파이프라인을 탄다.
- 실시간 생성 중에는 스켈레톤 UI/로딩 카드를 표시하고, 평균 15초 이내
  응답을 목표로 한다(00-overview-prd.md KPI와 동일 기준).

## 5. 기능 요구사항 (MoSCoW)

**Must**
- 프리셋 7종 선택 UI, 선택 즉시 사전 생성 코스 3개 이상 노출
- "더 보기" 클릭 시 실시간 코스 추가 생성
- 커스텀 조건 직접 입력 폼(일정/인원/이동수단/예산/취향)
- 코스 결과 카드에서 찜 버튼 노출 (→ `04-favorites-prd.md` 연동)

**Should**
- MBTI 4글자 입력 및 매핑 결과 설명 툴팁("당신의 ENFP 성향엔 이런 코스가 어울려요")
- 축제 배지 표시 및 축제 상세 정보 링크

**Could**
- 과거 찜 이력 기반 추천 가중치 반영 (2차 이후)
- 프리셋 조합(예: "연인 + 반려동물") 다중 선택

## 6. 화면/UX 요구사항

- 홈 화면 상단: 프리셋 7종을 카드/칩 형태로 가로 스크롤 배치 (모바일
  기준 한 화면에 3~4개 노출, 나머지는 스와이프)
- 프리셋 선택 → 결과 리스트 화면: 코스 카드(제목, 대표사진, 일자수,
  주요 스팟 3개 미리보기, 찜 버튼) 3개 이상 즉시 표시
- 결과 리스트 하단 "다른 코스 더 보기" 버튼 → 로딩 상태 → 카드 추가
- 커스텀 입력은 별도 폼 화면(또는 하단 시트)으로 진입

## 7. 데이터/연동 요구사항

- `docs/agents/` 5개 에이전트 파이프라인 재사용 (배치/실시간 모두)
- 신규 데이터: `festival_calendar` 테이블, `mbti_tag_mapping` 테이블,
  `precomputed_courses` 캐시 테이블(프리셋별, 생성일시, TTL 포함)
- 오케스트레이터 입력 스키마에 `preset_type`, `mbti`, `travel_date` 필드 추가

## 8. 비기능 요구사항

- 사전 생성 코스 노출 지연 ≤ 0.5초 (캐시 조회만 수행)
- 실시간 추가 생성 ≤ 15초, 실패 시 재시도 안내 메시지
- 반려동물 동반 프리셋은 `pet_allowed` 미확인 업체를 후보에서 하드 제외
  (오탐 시 사용자 신뢰 저해 리스크가 크므로 Must 수준 필터)

## 9. 성공지표

- 프리셋 클릭률(홈 방문자 대비) ≥ 40%
- "더 보기" 클릭 후 실시간 생성 완료율 ≥ 95%
- 프리셋별 찜 전환율 비교로 인기 프리셋 파악(운영 지표)
