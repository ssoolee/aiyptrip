# PRD-00. 서비스 개요 — 양평 AI 여행 코스 추천 웹서비스

## 1. 배경 및 문제 정의

양평군 여행객은 맛집/카페/관광명소/숙소 정보가 여러 채널(블로그, 지도앱,
SNS)에 흩어져 있어 하나의 일관된 "코스"로 조합하기 어렵다. 특히 계절,
동행 인원, 이동수단, 예산 같은 개인 조건까지 고려한 코스를 짜려면
많은 시간이 소요된다. 본 서비스는 AI가 사용자의 조건을 입력받아 양평군
내 코스를 자동 추천하고, 지도·사진·연락처 등 실행에 필요한 정보를
한 화면에서 제공한다.

## 2. 목표

- 사용자가 5턴 이내 대화/입력만으로 실행 가능한(영업시간·동선이 검증된)
  1~2일 여행 코스를 받을 수 있게 한다.
- 추천 코스를 "찜"해 두었다가 나중에 다시 보거나 비교할 수 있게 한다.
- 모바일에서도 데스크톱과 동일한 기능을 불편함 없이 쓸 수 있게 한다
  (반응형 웹, 별도 앱 없음).

## 3. 타겟 사용자 (페르소나)

| 페르소나 | 특징 | 핵심 니즈 |
|---|---|---|
| 커플 당일치기 | 서울/수도권 거주, 차 없음 또는 렌트, 감성 카페·뷰 맛집 선호 | 짧은 동선, 인스타 감성 스팟 |
| 가족 여행(아이 동반) | 자차, 1박 이상, 체험형 관광지 선호 | 주차, 유모차/아이 편의시설, 여유로운 일정 |
| 친구 그룹 액티비티 | 자차/렌트, 당일~1박, 액티비티·맛집 위주 | 다양한 활동, 가성비 |
| 반려동물 동반 | 자차, 반려동물 동반 가능 업체 필수 | 동반 가능 여부 필터 |

## 4. 여행 계획 시 고려해야 할 모든 요소 (요구사항 도출 기준)

AI 추천 로직과 필터가 아래 요소를 모두 입력/반영할 수 있어야 한다.

- **일정**: 당일/1박2일/2박3일, 방문 요일(평일/주말), 계절/날씨
- **인원/동행유형**: 혼자/커플/가족(아동 동반 여부)/친구/반려동물 동반
- **이동수단**: 자차, 대중교통, 자전거(따릉이 등), 도보
- **예산**: 1인당 예산 범위(식비/숙박비 별도 또는 통합)
- **취향/테마**: 자연/힐링, 액티비티(레포츠), 맛집 탐방, 카페 투어,
  사진 명소, 문화/역사, 온천/스파
- **접근성/편의**: 주차 가능 여부, 휠체어/유모차 접근성, 화장실
- **실행 정보**: 영업시간, 정기휴무일, 실시간 혼잡도, 예약 필요 여부
- **의사결정 보조 정보**: 사진, 리뷰 요약, 평점, 연락처, 지도/경로

이 요소들은 [01-ai-course-recommendation-prd.md](./01-ai-course-recommendation-prd.md)의
입력 항목 설계에 직접 반영된다.

## 6. 성공지표 (KPI)

- **추천 완료율**: 코스 추천 요청 시작 대비 결과 수신 완료 비율 ≥ 90%
- **찜 전환율**: 코스 결과를 본 사용자 중 1개 이상 찜하는 비율 ≥ 25%
- **재방문율**: 7일 내 재방문 후 찜 목록 재조회 비율 ≥ 15%
- **평균 추천 응답 시간**: 15초 이내 (에이전트 파이프라인 전체)
- **모바일 트래픽 이탈률**: 모바일 세션 이탈률이 데스크톱 대비 +10%p 이내

## 7. 비기능 요구사항 (공통)

- 모바일 반응형 (360px~1440px 대응), Core Web Vitals 준수(LCP < 2.5s)
- 개인정보: 위치 정보는 사용자 동의 하에만 수집, 찜 데이터는 로그인
  사용자 기준으로 서버 저장 (비로그인은 로컬 저장 후 로그인 시 병합)
- 외부 API(네이버 검색, TourAPI) 장애 시에도 캐시 데이터로 서비스 지속
  가능해야 함
- **인프라**: 배포는 Firebase Hosting/App Hosting, 인증은 Firebase
  Authentication, DB는 Cloud Firestore, 서버 로직은 Cloud Functions for
  Firebase로 구성한다 — 상세는 [06-infra-deployment-prd.md](./06-infra-deployment-prd.md),
  전체 외부 API 목록은 [07-external-api-integration.md](./07-external-api-integration.md) 참조

## 8. 범위 제외 (Out of Scope, 1차 출시)

- 결제/예약 연동(맛집·숙소 실시간 예약)은 1차 출시 제외, 외부 링크 연결로 대체
- 회원 간 코스 공유 커뮤니티 기능은 2차 이후 검토
- 양평군 외 지역 확장은 이번 범위에서 제외

## 9. 마일스톤 (제안)

1. MVP: AI 코스 추천(단순 조건) + 지도/업체정보 + 찜 (로컬 저장)
2. v1.0: 로그인/회원 찜 동기화, 검증 에이전트 고도화, 반응형 완성도 향상
3. v1.1: 개인화 추천(과거 찜 이력 기반), 리뷰 요약 고도화
