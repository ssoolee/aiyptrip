# MBTI 유형별 추천 코스 근거 자료

`/course/mbti/{TYPE}` 화면에 먼저 보여주는 큐레이션 코스와 숙소·펜션 추천의 근거.
원천 데이터는 `data/mbti-courses.source.json`, 앱이 읽는 결과는 `npm run build:mbti`로
만든 `src/lib/data/mbtiCourses.json`이다 (결정 사항: `docs/prd/01-ai-course-recommendation-prd.md` §3.2).

## 원본 문서 (자료 확인일 2026-09-28)

1. **MBTI별 양평군 식당·카페·여행지 매칭** (11쪽): 16개 유형마다 식당·카페·여행지를
   1곳씩 고르고 연결 이유를 적은 추천안.
2. **MBTI별 양평군 숙소·펜션 매칭** (11쪽): 16개 유형마다 숙소 1곳(양평군 내 숙소·숙박
   브랜드 11곳)을 골라 기본 성향 → 숙소 특징 → 매칭 이유 → 이용 제안 → 예약 전 확인 순으로
   정리한 추천안.

원본 PDF는 저장소가 공개라서 커밋하지 않았다. 내용은 원천 데이터의 `reason`·`notice`·
`summary` 필드에 요약해 옮겼다.

## 해석의 한계 (원문 고지)

- 성향과 장소의 연결은 **해석에 따른 추천**이다. MBTI별 실제 방문 선호도를 조사한 결과가 아니다.
- MBTI 유형의 기본 성향은 Myers & Briggs Foundation의 16개 유형 설명을 참고 틀로만 썼다.
- 영업시간·휴무·메뉴·가격, 체험시설 예약·당일 운영, 객실 판매 여부·총요금과 부대시설 포함
  범위는 방문·예약 전에 확인해야 한다.

## 코스 구성 방식

- 유형마다 문서의 식당 → 카페 → 여행지 순서 그대로 당일 코스 1개(점심 12:00, 카페 14:00,
  여행지 15:30)로 만들었다. 코스 제목은 문서의 유형별 소제목, 화면의 성향 설명은 숙소편의
  "기본 성향" 문장이다.
- 숙소는 코스와 따로 "{TYPE}에게 어울리는 숙소·펜션" 섹션에 보여준다.
- 문서 여러 유형에 같은 장소가 나오면(예: 하우스베이커리, 생각속의집) 유형별 연결 이유를 각각 쓴다.

## 장소 확정 결과 (2026-09-28 빌드)

- 원천 데이터의 장소 이름 41개 중 40개를 좌표까지 확정했다(스냅샷 일치 또는 TourAPI·네이버 지역 검색 이름 일치).
- **양평레일바이크**는 네이버 지역 검색·TourAPI 어디에서도 찾지 못해 ISTP 코스에서 빠졌다
  (식당·카페 2곳만 노출). 운영 여부를 확인한 뒤 정확한 주소를 원천 데이터에 넣고 다시 빌드한다.
- 주소 Geocoding(NCP)은 상품 구독 전이라 현재 동작하지 않는다.
